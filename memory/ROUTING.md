# 命令路由

| 用户说法 | 命令 |
|---------|------|
| 初始化 / 开始管这个项目 | `/pm-init` |
| 现在怎么样 / 今天做什么 | `/pm-status` |
| 下一步做什么 | `/pm-next` |
| 这个做完了 / 关闭 TODO-xxx | `/pm-done` |
| 帮我看这个报错 + 粘贴 | `/pm-fix` |
| 全面检查 / 体检 | `/pm-all` |
| 生成大纲 / 空项目规划 | `/pm-outline` |
| 章程 / constitution / 导入需求 | `/pm-charter` |
| 导出治理摘要 | `/pm-export` |

日常只需记住：`init` → `status` → `done`；出事用 `fix`；发版前 `all`。
